**Role: Analytics Engineer** · [Team repository](https://github.com/HackaThon-jok/datathon) · [My merged contribution, PR #2](https://github.com/HackaThon-jok/datathon/pull/2)

My analytics workstream focused on migrating a legacy sales report into structured analytical models and checking that the results remained consistent with the original report.

The delivery includes:

- Python/DuckDB staging and monthly reporting models, with explicit field mappings.
- Data-quality checks and reconciliation against the original report, including a demonstration that blocks incomplete data even when revenue still matches.
- Schema contracts, versioned outputs, local rollback and a 31-test acceptance suite at the PR #2 delivery point.
- Athena SQL and evidence-collection utilities for the team's cloud integration.
